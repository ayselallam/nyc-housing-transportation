# NYC Housing & Transportation Project — Milestone 1

## Datasets
- Housing: Affordable Housing Production by Building (`hg8x-zxpr`)
- Transportation: Automated Traffic Volume Counts (`7ym2-wayt`)

## Files
- `NYC_Housing_Transportation_Milestone1.ipynb`: notebook workflow for EDA, cleaning, aggregation, integration, charts, limitations, and team contributions.
- `app.py`: Dash website.
- `requirements.txt`: Python dependencies.
- `nyc_housing_traffic_integrated.csv`: generated by running the notebook; place it beside `app.py`.

## Run the notebook
1. Upload the notebook to Google Colab.
2. Run cells from top to bottom.
3. If the notebook cannot identify the housing counted-units field, inspect `housing.columns` and set `unit_col` to the field matching the official "Counted Units" definition.
4. Save the executed notebook and download `nyc_housing_traffic_integrated.csv`.

## Run the website locally
```bash
pip install -r requirements.txt
python app.py
```
Open the local Dash URL printed in the terminal.

## Deployment
Deploy the repository to Render or another supported Python hosting service. Set the start command to:
```bash
python app.py
```
Ensure the generated CSV is included in the deployed repository.

## Team contribution
Replace the Member 1–5 placeholders in the notebook with real names and record only work actually completed.

## Important analytical limitation
Traffic counts are intermittent 15-minute samples at selected roadway locations. They are not a complete borough-wide traffic census. Housing project start dates are project financing/regulatory milestones and do not necessarily represent occupancy. Do not claim causation from correlation.
